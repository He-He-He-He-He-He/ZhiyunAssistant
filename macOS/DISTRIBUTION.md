# 发行注意事项

本地构建为 ad-hoc 签名，未经过 Apple Developer ID 签名及公证。正式发行需使用发行者自己的证书并完成公证；证书、私钥、API 密钥、账号数据、浏览器会话、课程内容和用户笔记均不可放入源码或安装包。

AI 功能需要用户自行配置个人 API 或本机模型。MCP 接口默认关闭，启用后同一 macOS 用户的本机程序可能操作应用数据。

## 可选 Developer ID 签名与公证

仅在发行者明确提供身份与已配置的钥匙串公证配置后，运行：

```sh
ZHIYUN_SIGN_IDENTITY="Developer ID Application: 发行者 (TEAMID)" ZHIYUN_NOTARY_PROFILE=发行者公证配置 bash build.sh
```

只设置签名身份并不等于完成公证；不设置变量时为 ad-hoc 构建，首次打开可能受到 Gatekeeper 阻止。脚本先公证并装订 staging 应用，再生成 DMG 和 ZIP，之后单独公证和装订 DMG。签名与公证路径需在持有有效证书的发行环境验收，本机 ad-hoc 构建不构成该路径已验收的证明。

1.8.9（build 24）未启用自动校园密码填写或提交，仅支持官方页面手动登录。凭据与会话密钥保存在本机加密文件；团队签名版本使用系统钥匙串中的随机主密钥，ad-hoc 版本使用本机标识与安装盐派生密钥，不能防范同一 macOS 用户下的其他程序读取。删除墓碑及会话代数用于防止旧进程或旧钥匙串副本重新迁入已删除资料。
