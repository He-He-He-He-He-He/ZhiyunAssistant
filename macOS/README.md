# 智云助手 · macOS

智云助手帮助用户查看自己有权限访问的课堂课件、转写和回放，并提供笔记、离线下载及 AI 辅助学习。此目录是 macOS 客户端源码；课程访问遵循智云课堂实际权限。

## 安装与使用

应用需要 macOS 13 或更新版本。在本机打开后，通过浙江大学官方认证登录。课程、笔记和离线资源保存在本机；学习资料仅在用户使用 AI 功能时发送给所选服务。AI 功能支持用户自行配置的 DeepSeek API 或本机模型；调用个人 API 的费用由用户账户承担。模型回答可能有误，应结合课堂原文核对。

应用提供本机 MCP 接口，可在“隐私与数据”中启用，并通过“AI 帮你装”复制通用配置说明。接口开启后，同一 macOS 用户下的本机程序可能读取和操作课程、笔记，请只在信任本机环境时启用。系统认证和文件选择仍需用户完成。详见 [AGENT_MCP.md](AGENT_MCP.md)。

## 首次安装

1. 打开下载的 DMG，将「智云助手」拖到「应用程序」文件夹，再从「应用程序」尝试打开一次。
2. 当前预览版未经 Apple 开发者签名和公证。如果系统提示无法验证开发者或阻止打开，请确认文件来自本仓库的发布页，再进入 **苹果菜单 → 系统设置 → 隐私与安全性**。
3. 向下找到「安全性」，点击智云助手对应的 **仍要打开**，按系统提示认证，并在弹窗中确认「打开」。
4. 完成后通常可以正常双击打开应用。若看不到「仍要打开」，先再次尝试打开应用，再回到上述页面。

操作位置属于 macOS 的系统设置。详见 [Apple 官方打开 App 说明](https://support.apple.com/zh-cn/102445)。

## 源码构建

需要 Xcode 命令行工具和 Node.js 20 以上版本：

```sh
npm ci
npm run verify
npm test
bash build.sh
```

构建产物位于 `build/`，本地构建使用 ad-hoc 签名，未经过 Developer ID 签名和公证。源码与安装包不应包含 API 密钥、证书、账号、会话、笔记、互动记录或真实课程资料。

## 检查更新

在「隐私与数据 → 版本更新」查看当前版本、手动检查或关闭每日自动检查。检查只获取本仓库在 GitHub 上的公开版本与安装包信息；发现新版后由用户打开发布页并自行安装。旧版本需要先手动安装带检测功能的新版。
