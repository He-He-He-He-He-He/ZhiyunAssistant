# Internal Android integration contract

Android sources: app/src/main/java/cn/suike/slides/android. Native JavascriptInterface name NativeBridge.
- sync(method: String,payloadJson: String): String returns JSON {value: any} or {error: string}; only sandbox file primitives, cookie reads, app paths and validated resource registry map operations are synchronous. No networking/large image work on sync.
- post(id: String,method: String,payloadJson: String): void schedules async work; calls window.__androidReceive({id,value,error}) on UI thread. JS event entry window.__androidEvent({name,value}).
- Low-level bridge global window.androidNative: {call, sync, on}. App's window.zhiyun is higher-level JS services.

## Native saved-account acceptance gate (beta.7)
app.nativeAccountSettings {} only opens native consent UI; renderer payload credentials/consent are ignored. Opening it does not enable authentication. Saving requires the native password field and separate checked consent controls, one private CAS POST, strict infosimple identity verification, then encrypted atomic credential save and official-session adoption. JavaScript cannot read saved credentials or provide verification proof.

Native automatic authentication starts disabled on every NativeIO/Activity instance. Only the native enable button or a successfully consented native enrollment enables this instance. app.silentLogin is an internal compatibility entry, not a way around the gate: it requires an actual official 401 marker, foreground state, current cancellation generation, saved consent and a durable one-shot reservation. Status 403, network failures, session restore and page/settings entry never trigger CAS. One automatic allowance remains spent across success/failure/restart; background/logout cancels queued/in-flight work and blocks stale publication.

## Safe diagnostics and anonymous production preflight
app.viewNativeDiagnostics {} opens a read-only native window. It never requests credential state, authentication, or network data. It is available before login and before the global privacy-consent screen is accepted. app.nativeAnonymousPreflight {} only opens a native confirmation; renderer parameters, credentials, URLs and consent flags are discarded. Neither operation returns report bodies or grants enrollment/automatic-login permission to JavaScript.

Only the positive native preflight button may invoke the GET-only production adapter. It uses the same raw-TLS implementation, bounded HTTP parser, form/key/captcha regex and private fresh cookie jar as enrollment, but has no POST capability. It never enters the credential store/reservation/publication path. Preflight success is not proof of authenticated identity. A captured generation is rechecked when queued work begins; background/logout also cancels it.

NativeCasDiagnostics stores only numeric operation/time/HTTP fields and fixed enums (stage, operation kind, result, POST state, exception category, cleanup category, persistence state). Stage coverage includes revoke/store/enrollment/session/discovery/form/key/captcha/reserve/POST/callback/OAuth/landing/identity/official verification/save/commit/cleanup. No exception message/cause/class name, URL, redirect parameter, cookie, password or account is serialized or displayed. NativeVerificationGate retains typed failures rather than replacing callback exceptions with a boolean-only outcome.

The latest report is atomically replaced outside the renderer filesystem roots; a shared per-file operation sequence rejects late completions/cancellations/store-read errors. Failure to persist is a sticky explicit marker, not permission to retry; it does not alter the credential allowance. A persisted RUNNING report becomes INTERRUPTED after process restart. Reading a report cannot recover unrecorded failures from older releases or determine whether an uncertain POST authenticated remotely.

app.invalidateSession invalidates generations before cleanup; app.revokeNativeCredentials durably revokes native saved-account consent; app.clearOfficialCredentials removes legacy encrypted aliases; app.cancelSilentLogin cancels native work without dispatching authentication. app.checkLoginProfiles reports unknown legacy isolation residue but neither adopts nor removes it. The old WebView verifier and profile-cleanup mutation entry remain disabled.
