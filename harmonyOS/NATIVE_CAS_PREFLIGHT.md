# 原生 CAS 预检与手动验收边界

本文件对应 0.7.10 / versionCode 37 的公开源码和 release unsigned HAP。编译、合成资料回归和静态审计不等于真实学校认证或端到端真机验收；本轮未连接、安装或操作设备。

## 生产默认与同意

- `NATIVE_CAS_REAL_POST_ENABLED`、`CREDENTIAL_FEATURE_ENABLED` 默认均为 false；已有加密密码和持久同意记录不能自行启用认证。
- 匿名预检入口为「隐私与数据 → 开发测试：匿名登录预检」。仅在点击开始后发送匿名 GET，不输入密码、不读取浏览器 Cookie 或凭据库，不消耗登录尝试。SDK 本机 RSA 能力检查只使用固定公开探针字符串。
- 真实手动测试入口为「隐私与数据 → 原生账号验收（测试）」。须先通过官方页面取得 canonical username、id、tenantId，再由用户本人输入密码、阅读弱 RSA/验证码/限流及保存风险，明确勾选同意后点击验证保存。打开页面、未勾选、网页消息及离线演练均不能授予许可。
- 许可只在本次启动内存中存在并绑定已验证账号。退出、切号、重启撤销；取消或后台终止在途认证。许可重建、返回前台及失败均不能恢复已消耗的重登额度。
- 原生未知身份首登不在本轮范围，保留官方 WebView 登录。输入别名仅作提交凭据，不从其推断官方身份，不捕获或自动保存官方页面密码。

## 会话采用与身份验证

- 原生 CAS Cookie jar 与共享 WebView 隔离，只允许固定白名单 HTTPS，禁用自动跳转，不弱化 TLS 校验，不配置持久系统 CookieRepository。
- JSESSIONID 在表单、公钥及验证码请求之间核对完整作用域和变化代数。允许辅助 Cookie 改变，但不能用删除/重建或同名 shadow 绕过会话固定。
- ticket / OAuth code 按有界 opaque 值处理，保留原始 query 拼写，只严格解码一次，不把 `+` 当空格，不重复编码或解码。来源、路径、参数名唯一性、控制字符及 UTF-8 检查保留。
- 512 位应用层裸 RSA 是官方旧协议兼容，不代表现代安全强度，也不是 TLS 的替代。实际设备 SDK 能力仍须用户另行验收；不宣称离线 Node 适配桩证明了真机 RSA 可用。
- `infosimple` 身份必须匹配 canonical account、id、tenant。逐对象 JSON tokenizer 解码键后查重，拒绝重复键和转义别名歧义，允许姓名值中的 `\u5f20\u4e09` 等合法转义；不同对象可使用相同键。要求自身身份字段，拒绝错误结构、尾随数据、过深或过大的 JSON。
- 401 重登先持久消耗唯一预留，再创建一次 CAS 流程；网络失败、403、验证码、取消及交互来源的 401 不自动重试认证。
- 已验证 Cookie 先写分片和 pending manifest 并返回 receipt，随后保存账号、确认本次尝试、提交最终 manifest，最后同步发布 current。pending 会话不能冷恢复；取消或失败按 manifest/adoption 身份回滚，不能擦掉新账号提交。
- 已确认后最终发布失败，按持久 attemptId 将本次额度恢复为已消耗，不误伤后来重新验证保存的新凭据。安全存储拒绝补偿会报告 STORAGE，不虚称已成功清理。
- 成功发布前不更新首页账号、课程权限或下载 scope。错误仅显示固定阶段/类别、HTTP 状态和允许的数字 SDK 码，不输出密码、Cookie、票据、官方正文或未知异常信息。

## 离线演练与回归

「开发测试：原生保存与重登离线演练」使用纯内存存储和合成传输，不创建真实认证请求，不访问真实 Asset，也不授予真实许可。

`npm test` 覆盖 core、native-cas、native-login 共 576 项。回归包含真实 Store 逻辑加内存 Asset 桩、采用后账号/确认窗口取消、失败及冷恢复、新账号和 slot ABA 保护、最终 Cookie 已落盘后的失败、发布顺序、额度补偿、Unicode 值、转义键查重和自身字段检查。测试不替代触控、硬件存储、设备 RSA 或学校认证验收。

## 公开分发与后续验收

GitHub 公开产物须为 release、debug=false、unsigned HAP；未签名包不能直接安装，须按 [INSTALLATION.md](INSTALLATION.md) 用下载者自己的合法签名材料签名。不得公开任何设备绑定 debug signed HAP、私人证书、私钥、设备 Profile、设备标识、个人路径或本机构建日志。

默认与示例构建配置均不带签名。已有 code36 本地验收包独立保留，不因本次源码同步或公开 release 构建而重签、覆盖或安装。本轮没有提交、推送或创建 GitHub Release；后续真机反馈应明确区分匿名预检、SDK 加密、真实认证和会话业务恢复各阶段，发现问题继续先离线复现修复，不宣称端到端已通过。
