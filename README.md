# 智云助手

智云助手是面向课堂学习的多端应用，把有权限访问的课程课件、课堂转写、视频与笔记组织在同一条时间线上，帮助用户定位内容、记录和复习。

项目包含 [macOS](macOS/README.md)、[HarmonyOS](harmonyOS/README.md)、[Windows](windows/README.md) 和 [Android](android/README.md) 客户端。各端功能和验证程度有所不同，资料保存在本机；目前不提供跨设备自动同步。

## 主要功能

- 查看课件和课堂转写，按时间与课件页定位内容；按需播放视频。
- 记录课堂笔记、插入课件和转写引用，并回到原始时间位置。
- 收藏课程、保存学习进度，选择所需资料下载以供离线查看。
- 使用自己配置的 DeepSeek API 进行课程问答和辅助学习；Mac 还支持本地模型与可启用的 MCP 接口。

课程登录使用浙江大学官方认证，应用遵循账号的实际访问权限。AI 功能只在用户主动使用时向所选服务发送相关资料；结果可能有误，请结合原文核对。

使用前请阅读[安全说明](SECURITY.md)，了解当前版本的凭据和本机接口限制。

## 安装与开发

各平台的依赖、构建、签名和安装要求见各自目录。HarmonyOS 设备安装请先阅读[签名与安装说明](harmonyOS/INSTALLATION.md)。Git 中的源码更新并不等同于已经发布或通过应用商店审核；历史安装包的功能和配置以各自发布时的说明为准。

提交和分发时不要包含个人 API 密钥、证书和签名文件、账号与登录会话、真实课程内容、笔记、对话或下载缓存。应用为独立开发工具，不代表浙江大学或智云课堂运营方。第三方组件版权与许可证见各平台目录中的 `THIRD_PARTY_NOTICES.md`。
